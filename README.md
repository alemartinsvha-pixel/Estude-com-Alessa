# Estude com Alessa
Pacote de escritório acessível, brasileiro e com propósito.
**Todo mérito é de Deus - Ele segura minhas mãos.**

## Módulos
- 📝 Editor de Texto acessível
- 📊 Planilha simples e falada
- 🎤 Slides sem caixas invisíveis

## Como compilar no GitHub (para Alessandra)
1. Crie um repositório novo no GitHub com nome `estude-com-alessa`
2. Faça upload de todos esses arquivos
3. Vá na aba **Actions / Ações**
4. Ative o workflow. Ele vai compilar automaticamente em EXE
5. Baixe o EXE na aba Actions > Artifacts

## Rodar local
python src/main.py

Deus abençoa cada linha de código!
